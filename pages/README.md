# TermuxBridge Cloudflare Pages — live GitHub Mode 2

This is the canonical source for `https://termuxbridge.pages.dev/` (no installer HTML interface).

- On **every GET** or HEAD, the Router adds a six-digit random query value, reads the latest commit SHA through GitHub's public Atom feed with `no-store`, and retrieves `install.sh` from the **immutable current commit**. This avoids GitHub raw branch CDN returning cached, stale files.
- Both `/` and `/install.sh` return HTTP `200`, `text/plain; charset=utf-8` at the original Pages hostname. Browsers, CLI and PowerShell/Termux get identical bytes. `POST` returns 405.
- `X-CFPR-Freshness-Source: github-atom-sha` and `X-CFPR-Git-Commit` identify the live source readback. `Cache-Control: no-store` prevents browser caching.
- Source binding: Cloudflare Pages environment `REDIRECT_URL=https://raw.githubusercontent.com/ZTD38F/TermuxBridge/main/install.sh` configured in **production and preview**. The advanced `_worker.js` is generated by `ZTD38F/Cloudflare-Pages-Router` (PR #13), not manually forked.
- No hard-coded 40-character source commit is used. Changes merged to `main` are automatically resolved without redeploying Pages. Availability and timing still depend on GitHub and Cloudflare; there is **no guaranteed instant propagation SLA**.
- For high traffic or inaccessible Atom feeds, GitHub Contents API is a fallback. Configure an optional repository-scoped read-only `GITHUB_TOKEN` secret for authenticated fallback; do not use broad personal tokens.
- The `index.html` file is a safety fallback only; the old Secure Install HTML, `_redirects` and legacy app assets are not deployed. The Win+R/Ctrl+V/Enter instructions belong to CyberVoid, not this script endpoint.

Tests: `node --test pages/site.test.mjs`. Build: `bash pages/build-site.sh <new-directory>` (exactly `_worker.js` and `index.html`).

Note: delivering a script over HTTPS and verifying its SHA does not prove that it was executed successfully on a device. Review branch protection and CI since this endpoint intentionally follows `main`.
